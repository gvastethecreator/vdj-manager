# VDJ Manager Privacy Policy

_Last reviewed: 2026-08-19_

VDJ Manager is designed around local-first management of VirtualDJ libraries.

## Data handled

The application reads files and directories selected by the user, including VirtualDJ library XML and associated local media/resource metadata. During explicit mutation workflows it may create backups, journals and temporary working files required to safely commit the requested operation.

## Network

Core library inspection and mutation do not require uploading the user's music library or documents to a remote service. The Store build must not add telemetry, advertising SDKs or remote content without a separate product and privacy review.

If the updater contacts a release endpoint, that request is limited to update metadata and package retrieval; it is not a library synchronization service.

## Storage

Uninstalling VDJ Manager must not delete the user's VirtualDJ libraries, music files, backups created by the user, or unrelated documents.

## Children

The application is a general-purpose desktop utility and is not directed to children.

## Changes

Material changes to data handling will update this policy before the corresponding release is submitted to the Microsoft Store.

## Contact

For privacy questions, use the contact mechanism published in the repository's current release metadata.
