# Store listing draft

## Title

VDJ Manager

## Short description

Inspect, repair, and maintain VirtualDJ libraries with safe, reviewable write workflows.

## Description

VDJ Manager is a Windows desktop workspace for understanding and maintaining VirtualDJ libraries. Find missing files, moved tracks, duplicates and stale references; inspect metadata, playlists, history, cues and waveforms; and review changes before applying them.

Safety is part of the product: mutations use backups, validation, optimistic concurrency, atomic commits, no-clobber rules and a per-library recovery journal.

The Store build is Windows x64. It is designed for users who want direct control over their local VirtualDJ library rather than a cloud migration workflow.
